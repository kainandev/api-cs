# Api em C# Lívia e Kainan

### Para inciar o desenvolvimento da API é necessário criar o banco de dados, para isso utilize o comando:

```sh
dotnet ef migrations add initial
```

### Para atualizar o banco de dados caso o Models seja alterado utilize:

```sh
dotnet ef database update
```

### Para iniciar.
```sh
dotnet run
```

### Para Acessar o Swagger da Api acesse com ela instânciada:
```
http://localhost:5142/swagger
```
